CPA税法｜10章总抽象地图

只加抽象层，不删除任何章内D/O/X/题库/答案解析
8个事实符号通用编译器10章映射原章节总目录
所有税法题先压成一张事实卡：A + Ω + E + S + M + P + τ + R

先识别“谁、什么、发生了什么、处于什么状态”，再处理“多少钱/多少量、凭什么证明、何时何地、有没有优惠例外”。这套符号只是总页索引语言，不替代章内规则。

关键边界：这里的 Ω / β / Γ 等是“总抽象层符号”，不是章内的 O/X/D ID。章内文件原封不动保留；点击“进入章内”仍回到完整训练、算子、X仓和题目审计。

一、8个事实符号：先把题目翻译成人类可控的变量

A

Actor｜主体/法律角色

谁在税法关系里承担、取得、控制、支付或扣缴？

Ω

Object｜实体/权利

到底在处理什么：货物、所得、资源、土地、车辆、房产、凭证、税额流……

E

Event｜事件

发生了什么法律/经济动作：销售、取得、占用、开发、转让、排放、书立……

S

State｜状态

对象目前处在哪个状态：用途、计税模式、监管、居民身份、项目阶段、是否免税……

M

Measure｜计量/税基原料

多少钱/多少量：价格、收入、成本、面积、吨位、污染当量、税额池……

P

Proof｜证据/凭证

税法凭什么接受这个事实：发票、合同、权属证、监测数据、资格、评估……

τ

Time–Place｜时点/地点

哪一天/哪一月/哪一年度、在哪个地点或来源地发生？

R

Relief/Exception｜优惠/例外

不征、免税、减半、扣除、抵免、退税、限额、名单、阈值等覆盖层。

二、通用税法编译器：9个动作

事实卡 → Γ税网入口 → ρ角色 → κ分类 → β税基 → α归属 → λ参数 → Ψ优惠 → Φ税额
　　　　　　　　　　　　　　　　↑ 若发生状态变化：Δ(S→S′) 后重新跑一遍
ΓScope Gate｜税网入口
Γ(E,Ω,S,τ) → IN / OUT

先判断这件事有没有进入该税种；不要一上来乘税率。

ρRole Resolver｜角色解析
ρ(A | E,Ω,S) → payer / withholder / bearer

把“参与者”压成真正的纳税、扣缴或承担角色。

κClassifier｜分类路由
κ(Ω,E,S) → category / mode

决定所得类型、税目、一般/简易、从价/从量、余值/租金等路线。

βBase Compiler｜税基编译
β(M,P,S)=Σ计入−Σ排除±调整

绝大多数“计税依据”都可还原为：收集→剥离→调整→得到Base。

αAllocator｜归属/分摊
α(Base | 时间/面积/数量/项目/用途)

把混合事实切到正确税期、空间、项目、所得池或应税部分。

λParameter Selector｜参数选择
λ(κ,S,τ,R) → rate / unit / threshold

税率、单位税额、限额和阈值应在路线确定后才出现。

ΨRelief Overlay｜优惠覆盖
Ψ(Tax/Base,R,condition)

优惠通常不是新税种，而是对已识别路线施加免、减、扣、抵、退、封顶。

ΦTax Assembler｜税额装配
Φ(Base,λ,mode) → Tax

最后才执行乘法、从量、复合、超率累进、税额池等装配。

ΔState Transition｜状态迁移
S ─E→ S′ ⇒ re-run(Γ…Φ)

退货、用途改变、免税条件消失、清算、复垦、失而复得等，本质是状态变了后重新编译。

三、D / O / X 在总抽象层里的位置

D = 问事实章内D主要在识别 A / Ω / E / S / P / τ 的边界：哪一个事实变化会让路径跳变？
O = 执行动作章内O主要实现 β / α / λ / Φ / Δ：编税基、分摊、选参数、算税额、处理状态迁移。
X = 提供参数与正列举章内X主要给 Γ / λ / Ψ / P 提供名单、阈值、税率、期限、证据要求和优惠条件。

四、一张“最低必要事实卡”

A
谁？法律角色是什么？
Ω
处理的实体/权利是什么？
E
本题真正发生了什么事件？
S
事件前后各处于什么状态？
M
有哪些金额/数量？哪些只是噪声？
P
凭什么证明、按什么替代证据？
τ
时点、期间、地点、来源地？
R
不征/免/减/扣/抵/退/限额？

做题时不必真的全部填写。只填能改变 Γ / ρ / κ / β / α / λ / Ψ / Δ 的事实。

五、10章如何实例化同一套符号

第02章

增值税

进入章内 →
Γ(交易×对象×用途×跨境) → ρ(纳税/扣缴) → κ(一般/简易/免/零) → β(销售额/销项−进项) → λ → Ψ → Φ；Δ=退货/红字/用途变化

A=销售方/购买方/扣缴方；Ω=货物、劳务、服务、无形资产、不动产；E=销售/进口/跨境/视同；S=纳税人身份、计税模式、用途；M=销售额/进项/销项；P=扣税凭证；τ=纳税义务时间/地点。

核心D示例：VD01 交易入口与对象原子化、VD05 用途与视同交易状态、VD15 进项资格与证据、VD21 税额池与抵减层级。

第03章

消费税

进入章内 →
Γ(应税消费品×征税环节) → κ(从价/从量/复合) → β(销售额/数量/组成价) → Ψ(前税扣除/出口) → Φ；Δ=委托加工/连续生产/退关

A=生产/委托/受托/进口主体；Ω=应税消费品；E=生产销售、自产自用、委托加工、进口、零售/批发特殊环节；S=税目规格、环节、用途；M=销售额/数量/组成价；P=委托与购进凭证；τ=环节与时地。

第04章

进入章内 →
Γ(主体连接点×所得来源) → ρ/κ(收入/扣除/资产/重组) → β(PBT±纳税调整−亏损) → α(项目/期间归属) → Ψ(优惠/抵免) → Φ；Δ=资产/重组/损失状态

A=居民/非居民企业及关联方；Ω=收入、成本费用、资产、权益；E=取得收入、支出、资产处置、重组；S=确认时点、权属、资格；M=利润总额、调整额、亏损、抵免限额；P=票据/合同/资格证据；τ=年度/来源地。

核心能力簇示例：主体与连接点、事项与经济实质、时间与状态、权属与价值流、证据与资格门、模式与处理顺序。

六、最值得迁移的9类“普遍规则”

1. 税网入口 Γ

进口待售≠进口自用；产生污染物≠直接排放；持有房产≠转让房地产。先问“有没有发生该税种关心的事件”。

2. 法律角色 ρ

参与交易≠纳税人；产权人与实际使用人、委托人与受托人、销售方与扣缴方都要先解析角色。

3. 状态优先 S

同一实体因用途、监管、身份、项目阶段改变，处理路线会变；状态通常比“东西叫什么”更重要。

4. 价值/数量边界 β

计税依据普遍是“属于本次应税对象的价值/数量”，不是会计数字机械搬运。

5. 血统与归属 α

外购资源、进项税额、LAT扣除项目、所得扣除、土地/房产用途，都要追踪它究竟归属于哪个应税对象/期间/空间。

6. 证据阶梯 P

成交价失效→替代估价；无证→据实/核定；监测失真→替代认定。证据状态常直接切换算法。

7. 参数后置 λ

税率、单位税额、阈值通常不是第一问。先选对对象和路线，再调用参数。

8. 优惠覆盖 Ψ

out / exempt / reduction / deduction / credit / refund 必须分层；不要把所有“少交税”混成一个优惠概念。

9. 状态迁移 Δ

退货、用途改变、清算、复垦、失而复得、免税条件消失，本质都是 S→S′ 后重跑规则，而不是背一条孤立例外。
